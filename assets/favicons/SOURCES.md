# Local favicon sources

The site uses local SVG icons. The glyph icons were derived from these sources.

- GitHub: https://github.com/fluidicon.png
- LinkedIn: https://www.linkedin.com/favicon.ico
- X: https://abs.twimg.com/favicons/twitter.3.ico
- arXiv: https://arxiv.org/static/browse/0.3.4/images/icons/favicon-32x32.png

The Ava Labs icon is a local red triangle.
